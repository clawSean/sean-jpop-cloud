Deployment

Archive first, verify second, swap last.

$ sean deploy-procedure
  1. archive current live root
  2. build and update source repo
  3. validate HTML, CSS, and links
  4. screenshot desktop + mobile
  5. copy to deploy root
  6. verify public HTTPS access

$ sean privacy-check
  public:   patterns, proof, architecture
  private:  contacts, secrets, credentials, raw memory

Architecture

Everything runs from one machine.

Single VPS

OpenClaw agent, Telegram gateway, Caddy web server, headless browser, git repos, and deployed sites all run on the same Ubuntu box.

File-first state

Memory, knowledge, project progress, and operational state are stored as plain files in git repos. No database. Survives restarts cleanly.
