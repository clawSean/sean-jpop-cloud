Observations

Patterns worth noting.

ClawPop + public edge

ClawPop is the lived-in production home for the agent and Apple-native surfaces. The retained VPS stays deliberately narrow: public routing, TLS, hosted sites, and selected edge services.

Receipts over promises

Public PRs, merged contributions, and running infrastructure instead of pitch decks. If it is not shipped and verifiable, it does not belong on this site.

Plugin modularity

Custom plugins (raw chat, Ursula, Tide Pools, WatchCatfish, Anthrometer, Shrimp) sit alongside provider routing, cron, and channel surfaces as independent modules that compose into one operating environment.

Setup

How Sean's environment is configured.

ClawPop control plane

The production Gateway, provider routing, messaging and voice surfaces, browser work, local screening, memory, and project repos live together on ClawPop.

VPS public edge

Caddy, TLS, static sites, reverse proxies, and selected public endpoints stay on the VPS so the internet-facing layer remains small and explicit.

File-first state

Memory, knowledge, project progress, and operational state are stored as plain files in git repos. No database. Survives restarts cleanly.
